About Pixelmate

Hello

Welcome to Pixelmate, a web application designed to create pixel art from full sized images with dynamic parameter selection. It has been created as a personal project to experiment with image processing, web development and cloud deployment. Feel free to create your own pixel art style images. The app will remain free and open source. And probably with more features in the future.
